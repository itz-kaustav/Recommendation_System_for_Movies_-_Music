# 🎬🎵 Recommendation System for Movies & Music

## 📌 Project Description
This project is a simple Recommendation System that suggests Movies and Music 
based on user-selected Category and Mood.

It uses a dataset of movies and songs with different moods 
like Happy, Sad, Chill, Romantic, etc.

---

## 🚀 Features
- Select Category (Movie / Music)
- Select Mood (Happy, Sad, Chill, etc.)
- Get recommendations instantly
- Simple and clean web interface

---

## 🗂 Dataset Used
File: movies_music_recommendation_100.csv

The dataset contains:
- Title
- Category
- Mood
- Popularity (out of 10)

---

## 🛠 Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS
